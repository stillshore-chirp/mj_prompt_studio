# GitHub配送 Skill

## 発動条件

MJ Prompt Studioの変更をIssueやPRで説明・追跡する時に使います。共通のcommit、検証、review、権限、委任、checkpoint、GitHub配送手順はCodex利用者ローカルの `AGENTS.md` に従い、このSkillでは重ねて定めません。

## Issueの固有要件

既存Issueの受け入れ条件、根拠、重複を確認します。新規・更新Issueには、[Issue quality gate](../../../docs/ai-governance/14-issue-quality-gate.md)に沿って目的、根拠、scope、非対象、受け入れ条件、検証方針、riskを記載します。IssueやPRの公開内容は[公開安全性Skill](../security-publication/SKILL.md)に従います。
