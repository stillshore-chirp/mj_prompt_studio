# AIエージェント向けUI/UX作業プロンプト

この作業は、アプリ本体UI、GitHub共同作業面、または両方の変更を含みます。

Codexの共通業務手順は利用者ローカルの `AGENTS.md` に従ってください。UI/UX作業では、repository rootと対象pathの `AGENTS.md`、`.agents/skills/ui-ux-review/SKILL.md`、`02-uiux-review-framework.md`、`03-evidence-and-completion-gates.md` を参照し、アプリ本体UIとGitHub共同作業面を分類してください。

アプリ本体UIでは、ユーザー価値、初見simulation、state matrix、accessibility、視覚階層、copy、熟練者効率、満足感・信頼感、反証review、前後screenshot、実行・未実行検証、残リスクを提出してください。P0が残る場合は完了扱いにしません。

GitHub共同作業面だけでは、変更した文言・項目・構造・link・公開安全性を証跡にし、GitHubが所有する未変更のplatform UIや製品UI向けstate matrixを対象に広げないでください。
