# 熟練者効率と反復利用

## 基本方針

初心者へ文脈、熟練者へ近道を提供し、反復作業の再入力・再選択・再確認を減らします。安全確認と無駄な確認を区別します。

## 確認対象

- よく行うprompt編集、AI提案、copy、reference選択、variant比較、結果reviewの手数。
- 同じbrief、parameter、filter、選択、入力をやり直していないか。
- 戻る、tab移動、再試行後に入力や選択が保持されるか。
- 前回設定、template、duplicate、一括操作、shortcut、auto-save、再試行を検討したか。
- 初回だけ必要な説明を折りたたみ・再表示できるか。

## P0 / P1

主要反復taskが不要な説明・確認・再入力で恒常的に妨害される、failureで最初からやり直す、主操作がまれな操作より見つけにくい場合はP0です。一括操作や前回設定で明らかに改善するが単体で完了できる、1〜2step多い、shortcutがない場合はP1です。

## 安全性との両立

削除、外部送信、LLM画像解析、API key保存、復元困難な上書きでは安全性を優先します。ただし確認画面でも対象、影響、取り消し可否を明確にし、過剰な反復負荷を避けます。
