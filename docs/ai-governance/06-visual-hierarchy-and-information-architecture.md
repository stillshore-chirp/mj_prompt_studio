# 視覚階層と情報設計

## 原則

重要なものを重要に見せ、関連情報を近くに置き、異なる対象を区別し、迷う前に次行動を示します。情報を減らすだけでなく優先度を明確にします。

## 3秒確認

画面を3秒見て、画面目的、現在地、重要情報、最初の行動、補助情報を答えられる必要があります。

## 主操作とgrouping

- 意思決定領域ごとに主操作を明確にし、複数の主操作を競合させない。
- 危険操作を主操作より強く見せない。
- 関連情報と操作、対象と適用範囲、tab/filter/search/件数のscopeを近接と境界で示す。
- Composer、Inspector、Jobsなど複数pane間の現在対象と連動範囲を示す。

## 読みやすさと密度

見出し、本文、補助、metaの差をつけ、日本語長文、prompt、parameter、数値、日時を読みやすくします。高密度で主操作を埋めず、低密度で一覧性や熟練者効率を落としません。狭幅でpaneが変形しても現在地と操作を保持します。

## 情報設計

ユーザーの制作目的に沿って分類し、内部agent名、schema、DB都合を漏らしません。同じ概念へ同じ名前を使い、tab階層を深くしすぎず、戻り先を明確にします。
