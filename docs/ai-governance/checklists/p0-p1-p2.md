# P0 / P1 / P2 チェックリスト

## P0: 完了不可

- [ ] ユーザー価値、対象、目的を説明できない。
- [ ] 画面目的、現在地、対象・適用範囲、最初の行動が分からない。
- [ ] 主操作が埋もれる、または意味不明なicon-onlyである。
- [ ] 読み込み、空、no-results、error、disabled、利用不可が混ざる。
- [ ] errorに原因、影響、回復がない。
- [ ] disabledの理由と有効化条件がない。
- [ ] keyboard、focus、name/label、contrast、target、構造に重大問題がある。
- [ ] 色だけで意味を伝える。
- [ ] 反復taskが不要な説明、確認、再入力で恒常的に妨害される。
- [ ] 削除、外部送信、API key、ユーザー資産に関わるUIが信頼できない。
- [ ] 成功、失敗、待機の結果が分からない。
- [ ] ユーザーを責める、不要な不安を煽る、実態以上に安心させる。
- [ ] state matrix、初見、反証、証跡がない。
- [ ] 未実行検証を成功扱いする。

## P1: 原則同じ変更内で修正

- [ ] tab、filter、件数、対象scopeが曖昧。
- [ ] 重要度と視覚的強調、用語、labelが少しずれる。
- [ ] 空、成功、error後の次actionが弱い。
- [ ] 反復手数や説明がやや多い。
- [ ] 待機、成功、失敗のfeedbackが弱い。

## P2: Issue化可

- [ ] 余白、文言、順序の微改善。
- [ ] shortcut、一括操作、補助説明の追加。
- [ ] 実利用調査や計測が必要な改善仮説。
