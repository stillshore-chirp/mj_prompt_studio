# アクセシビリティチェックリスト

- [ ] keyboardだけで主要taskを完了できる。
- [ ] focusが見え、隠れず、順序が自然で、閉じ込められない。
- [ ] 操作要素にaccessible nameがあり、表示labelと矛盾しない。
- [ ] icon-only、tab、dialog、menu、drag and dropに意味と代替操作がある。
- [ ] 見出し、landmark、list、tableの構造が正しい。
- [ ] error箇所、原因、修正方法が分かる。
- [ ] status messageが支援技術へ伝わる。
- [ ] 色だけで意味を伝えていない。
- [ ] text、非text部品、focusのcontrastが十分。
- [ ] targetが小さすぎず、文字拡大・狭幅で破綻しない。
- [ ] 自動検査と手動keyboard確認を両方報告した。
