# 認知心理学・認知アクセシビリティ原則

## 認知負荷と認識

- 画面目的、現在地、操作対象、適用範囲を見れば分かるようにする。
- 前画面の情報、内部ID、実装用語を覚えさせない。
- 操作候補、選択中、制約、過去入力を画面上に示す。
- ユーザーの制作工程に合わせ、ApplicationやDB構造を画面分類へ漏らさない。

## 注意と選択肢

- 主操作、警告、errorを自然に見つけられるようにする。
- 複数の強調を競合させない。
- 最初に必要な選択肢を出し、高度な設定は段階的に開示する。
- defaultは安全で妥当にする。固定LLM実行ポリシーを変更可能に見せない。

## 失敗と回復

errorの場所・原因・修正方法を示し、入力を保持します。必要に応じてUndo、戻る、再試行、cancel、下書き保存を提供します。LLM提案は適用前に差分確認できるようにします。

## 初心者と熟練者

初心者へ文脈を示しつつ、熟練者は説明を読み飛ばせ、反復taskが不要な確認やtutorialで妨害されないようにします。

## レビューへの変換

理論名を並べず、`認知原則 -> 画面上の観察点 -> Pass/Fail -> 証跡 -> 修正案` へ変換します。
