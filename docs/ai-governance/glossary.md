# UI/UX Governance Glossary

本文は日本語を原則とし、外部標準、tool識別子、一般的な技術用語だけ英語を残します。

| 英語 | 日本語での意味 |
|---|---|
| accessibility / a11y | 多様な利用者・環境で知覚・操作・理解できること |
| accessible name | 支援技術がcontrol名として扱う名前 |
| artifact | 証跡として残す成果物 |
| contrast | 文字や部品の見分けやすさを示す明暗差 |
| counter-review | 完了を却下するつもりで欠点を探す反証レビュー |
| evidence | 検証したことを示す証跡 |
| focus | keyboard操作で現在選ばれている場所 |
| gate | 完了前の合否条件 |
| happy path | すべて正常に進む成功pattern |
| icon-only | 文字labelなしでiconだけが意味を伝える状態 |
| landmark | 画面領域の意味を支援技術へ伝える構造 |
| microcopy | button、helper、errorなど短いUI文言 |
| novice simulation | 初見ユーザーとして迷いを探す疑似review |
| P0 | 残ると完了不可の重大問題 |
| P1 | 原則同じ変更内で直す問題 |
| P2 | 後続Issue化できる改善機会 |
| primary action | その場で最も重要な操作 |
| recovery | 失敗や間違いから戻る手段 |
| state matrix | 状態ごとの表示、理解、行動、回復、証跡の表 |
| target size | buttonなど操作領域の大きさ |
| trust | 状態、結果、警告、操作を信頼できること |
| utility | ユーザー目的に実際に役立つこと |
| visual hierarchy | 重要度を視覚的に伝える階層 |
| WCAG | Webアクセシビリティの国際標準 |
